## Як оновлюється архів

Після завершених сцен оновлюються дата й точка продовження, події хронології та пов’язані тематичні записи. Невідомі дані позначені прямо, попередні рішення зберігаються в історії змін GitHub. Автоматичної роботи поза активним чатом немає.

Цей пакет систематизує вже встановлені факти; він не додає нових сюжетних подій. Повного початкового архіву не відновлено, тому документи містять явні прогалини.
